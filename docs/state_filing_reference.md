# 50-State + DC Individual Income Tax Filing Reference (2025–2026)

> **Federal Context (2026):** IRS Direct File (`directfile.irs.gov`) was discontinued ahead of the 2026 filing season. For federal returns, taxpayers use **IRS Free File** (partner software for eligible AGI), **Free File Fillable Forms** (all 50 states, any income), commercial software, or **Print & Mail**. All state portals listed below are **state-only**—they do not file a federal return.

---

## Why "Free File Commercial Partners" Are Not Useful for Sending an Already-Completed 1040

Throughout the table below, states without their own direct state-run online filing portal rely on **Free File commercial partners** (private tax-software companies such as TaxAct, TaxSlayer, FreeTaxUSA, OLT / OnLine Taxes, FileYourTaxes, 1040.com, etc.) participating in the **IRS Free File Alliance** or a **State Free File program**.

These commercial partners **are not useful for our goal of helping a user transmit an already-completed Form 1040 (or state return)** for the following reasons:

1. **No Completed-Return Uploads:** Free File commercial partners are full **guided Q&A tax-preparation applications**, not transmission gateways. Users cannot upload a completed Form 1040 PDF or a JSON data packet from ActuallyFreeTaxes.com and submit it. Users must manually re-enter their W-2s, 1099s, deductions, and credits through the vendor's questionnaire so the vendor can generate its own Modernized e-File (MeF) XML from scratch.
2. **Federal-First Bundling:** Commercial software almost always requires preparing and e-filing the **federal** return inside their app first before they will generate or e-file the matching **state** return.
3. **Conditional Eligibility & Referral-Link Traps:** A \$0 filing fee is only unlocked if the user enters through the official IRS/state Free File referral link **and** meets that specific vendor's eligibility rules (typically an Adjusted Gross Income cap, age limit, or active-duty military status). Entering through the vendor's main homepage or exceeding the cap routes the user into paid retail tiers.
4. **Inconsistent State Coverage:** Not every IRS Free File partner includes free state filing in every state; some waive state fees only for specific participating states.

**Implication for ActuallyFreeTaxes.com:** For federal filing, **Print & Mail** and **IRS Free File Fillable Forms** (line-by-line entry using our 1040 Mirror cheat-sheet) remain the viable free paths for users who have already computed their return here. For state filing, only states with **direct state-run online portals** (or **Print & Mail** / **low-cost e-file**) avoid forcing the user back through a full commercial Q&A interview.

## Summary by Category

- **No General Personal Income Tax (9 states):** `AK`, `FL`, `NV`, `NH` *(prior-year I&D only)*, `SD`, `TN`, `TX`, `WA` *(capital gains tax only for high earners)*, `WY`
- **Free Direct State-Run Online Return Filing (21 jurisdictions):** `AL`, `CA`, `CO`, `CT`, `DE`, `DC`, `HI`, `IL`, `LA`, `MD`, `MA`, `MI`, `NE`, `NJ`, `NM`, `NC`, `OH`, `OR`, `PA`, `UT`, `WI` *(eligibility/form limits apply; `VA` also offers fillable e-Forms and `WV` offers direct credit claims on MyTaxes)*
- **Third-Party Software or Paper Mail Only (no full DIY state return portal):** `AZ`, `AR`, `GA`, `ID`, `IN`, `IA`, `KS`, `KY`, `ME`, `MN`, `MS`, `MO`, `MT`, `NY`, `ND`, `OK`, `RI`, `SC`, `VT`, `WV` *(full IT-140)*
